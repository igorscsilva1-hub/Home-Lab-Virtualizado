# Windows Server

## Objetivo

Implementar futuramente serviços Microsoft no Home Lab para simular uma infraestrutura corporativa integrada.

---

## Planejamento inicial

O Windows Server será utilizado para:

- Active Directory
- DNS
- DHCP
- Gerenciamento centralizado
- Autenticação de usuários
- Integração com ambiente Linux

---

## Objetivos da implementação

- Aprender conceitos de domínio
- Trabalhar gerenciamento centralizado
- Estudar serviços Microsoft
- Integrar múltiplos sistemas operacionais
- Simular ambiente corporativo básico

---

## Status atual

Fase ainda não iniciada.

Atualmente o foco do projeto está na finalização da infraestrutura de rede e configuração do OPNsense.
